The whole internet in one word: **Unsupervised**.

Billions of people, bots and brands, all talking at once, and nobody's
parents are home. Comment sections, group chats, crypto, cat videos, wikis
and conspiracy forums are the same thing at different volumes: everyone,
everywhere, unsupervised.

`main.ts` writes that one word to `/output/entry.txt` (12 characters, no
spaces) and checks it against the bounty's gate first: 1 to 30 characters,
not only white space.

## Run it

```sh
node main.ts
```
